Simulating the Position Sensor

  • 초기 위치, 속도, 잡음 표준편차로 센서를 만들고 read() 를 부를 때마다 한 단계 이동 후 측정 반환

  • 아직 교과서형 데이터, 실제 세계의 복잡한 거동은 이후 예제에서 차례로 추가
  • 조건: pos = (4, 3), vel = (2, 1), noise_std = 1, 측정 50 개
class PosSensor(object):
    def __init__(self, pos=(0, 0), vel=(0, 0), noise_std=1.):
        self.vel = vel
        self.noise_std = noise_std
        self.pos = [pos[0], pos[1]]
    def read(self):
        self.pos[0] += self.vel[0]
        self.pos[1] += self.vel[1]
        return [self.pos[0] + randn() * self.noise_std,
                self.pos[1] + randn() * self.noise_std]
pos, vel = (4, 3), (2, 1)
sensor = PosSensor(pos, vel, noise_std=1)
ps = np.array([sensor.read() for _ in range(50)])
plots.plot_measurements(ps[:, 0], ps[:, 1]);

Implement the Filter

  • 설계한 행렬을 tracker1() 로 묶고 직선으로 이동하는 로봇의 cm 측정 zs 30 개를 batch_filter 로 처리
  • 필터 출력(파란 선)이 잡음 섞인 측정 위를 매끄럽게 따라감, 측정은 cm 이므로 100 으로 나눠 m 로 표시
  • 조건: zs: PosSensor((0, 0), (60, 30), noise_std=10) 의 측정, R_std = 10 cm, Q_std = 0.04 m, dt = 1 s
def tracker1():
    tracker = KalmanFilter(dim_x=4, dim_z=2)
    dt = 1.0   # time step
    tracker.F = np.array([[1, dt, 0,  0],
                          [0,  1, 0,  0],
                          [0,  0, 1, dt],
                          [0,  0, 0,  1]])
    tracker.H = np.array([[100, 0, 0, 0],    # m to cm
                          [0, 0, 100, 0]])
    tracker.R = np.eye(2) * R_std**2
    q = Q_discrete_white_noise(dim=2, dt=dt, var=Q_std**2)
    tracker.Q = block_diag(q, q)
    tracker.x = np.array([[0, 0, 0, 0]]).T
    tracker.P = np.eye(4) * 500.
    return tracker
robot_tracker = tracker1()
mu, cov, _, _ = robot_tracker.batch_filter(zs)
plots.plot_filter(mu[:, 0], mu[:, 2])
plots.plot_measurements(zs[:, 0]/100, zs[:, 1]/100); plt.legend(loc=2);

8.3 Filter Order11

Constant Velocity Object

  • 매 단계 속도에 작은 잡음을 더하는 등속 물체와 표준편차 1 m 의 위치 센서를 시뮬레이션
  • 궤적(검은 점선)이 완전한 직선이 아님, 길을 걷는 사람이나 바람에 흔들리는 항공기에 해당하는 등속 시스템
  • 조건: x0 = 0, vel = 1 m/s, 속도 잡음 0.06, 측정 잡음 1 m, 50 단계, seed 124
class ConstantVelocityObject(object):
    def __init__(self, x0=0, vel=1., noise_scale=0.06):
        self.x, self.vel, self.noise_scale = x0, vel, noise_scale
    def update(self):
        self.vel += randn() * self.noise_scale
        self.x += self.vel
        return (self.x, self.vel)
def sense(x, noise_scale=1.):
    return x[0] + randn()*noise_scale
np.random.seed(124)
obj = ConstantVelocityObject()
xs, zs = [], []
for i in range(50):
    x = obj.update()
    xs.append(x)
    zs.append(sense(x))
xs = np.asarray(xs)
plots.plot_track(xs[:, 0])
plots.plot_measurements(range(len(zs)), zs)
plt.legend(loc='best');

8.4 Evaluating Filter Order13

First Order Filter

  • 잔차 = 실제 상태 - 추정을 P 대각의 σ 와 비교, Gaussian 이면 약 68% 가 ±1σ, 99% 가 ±3σ 안, 실제 센서는 5σ 까지 고려

8.4 Evaluating Filter Order14

Zero Order Filter

  • 같은 데이터에 위치만 추적하는 0 차 필터 적용, 매 예측이 위치 변화가 없다고 가정해 추정이 실제 위치를 계속 뒤따라감

8.4 Evaluating Filter Order15

Second Order Filter

  • 같은 데이터에 가속도까지 추적하는 2 차 필터 적용, 잔차를 1 차 필터(점선)와 비교, 노란 띠는 2 차 필터의 ±1σ
  • 위치 잔차(왼쪽 아래)는 이론 한계 안이지만 속도 잔차(오른쪽 아래)가 1 차보다 훨씬 큼, 측정 잡음을 가속도로 오인

8.7.1 Normalized Estimated Error Squared (NEES)28

NEES

  • 등가속 시스템을 2 차 필터로 추적한 결과의 단계별 NEES 와 그 평균(점선)을 계산
  • 평균 NEES 가 상태 차원 3 보다 작아 통과, 실행 중에도 계산 가능하지만 참값을 아는 시뮬레이션에서만 사용 가능
  • 조건: R = 6, Q = 0.02, 80 단계, dim_x = 3
def NEES(xs, est_xs, Ps):
    est_err = xs - est_xs
    err = []
    for x, p in zip(est_err, Ps):
        err.append(np.dot(x.T, inv(p)).dot(x))
    return err

print('passed' if eps < kf2.dim_x else 'failed')

8.12.1 Implementing Air Drag46

Air Drag and Wind

  • Euler 방법으로 항력과 바람을 포함한 공의 궤적을 단계별로 계산(항력이 비선형이라 해석해 없음), 무풍과 4.5 m/s 뒷바람 비교
  • 진공에서 약 230 m 날아갈 공이 공기 중에서는 약 120 m, 홈런 타구로 현실적인 거리
  • 조건: 초기 속도 49.2 m/s (홈런 타구 속도), 35°, (0, 1) m, dt = 0.1 s, drag_force(v) = v B2/m
v, dt, theta = 49.2, .1, radians(35)   # m/s, s, rad
def solve(x, y, vel, v_wind, launch_angle):
    xs, ys = [], []
    v_x, v_y = vel*cos(launch_angle), vel*sin(launch_angle)
    while y >= 0:
        # Euler equations for x and y
        x += v_x*dt
        y += v_y*dt
        # force due to air drag
        velocity = sqrt((v_x-v_wind)**2 + v_y**2)
        F = drag_force(velocity)
        v_x = v_x - F*(v_x-v_wind)*dt
        v_y = v_y - 9.8*dt - F*v_y*dt
        xs.append(x); ys.append(y)
    return xs, ys
x, y = solve(x=0, y=1, vel=v, v_wind=0, launch_angle=theta)
plt.scatter(x, y, color='blue', label='no wind')
x, y = solve(x=0, y=1, vel=v, v_wind=4.5, launch_angle=theta)
plt.scatter(x, y, color='green', marker='v', label='4.5 m/s wind')
plt.legend(scatterpoints=1);
