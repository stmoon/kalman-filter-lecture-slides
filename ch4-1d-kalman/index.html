4.5 Updates with Gaussians09

Updates with Gaussians

  • prior 와 likelihood 를 모두 Gaussian 으로 두고 두 Gaussian 의 곱으로 update 구현
  • 결과 평균은 prior 와 측정의 가중합, 분산은 두 분산의 결합으로 평균 값과 무관
  • 조건: prior N(10, 0.2^2), 측정 N(11, 0.1^2)
def gaussian_multiply(g1, g2):
    mean = (g1.var * g2.mean + g2.var * g1.mean) / (g1.var + g2.var)
    variance = (g1.var * g2.var) / (g1.var + g2.var)
    return gaussian(mean, variance)
def update(prior, likelihood):
    posterior = gaussian_multiply(likelihood, prior)
    return posterior
# test the update function
predicted_pos = gaussian(10., .2**2)
measured_pos = gaussian(11., .1**2)
estimated_pos = update(predicted_pos, measured_pos)

def converged_variance(process_var, sensor_var, N=50):
    x = gaussian(0., 400.)

4.8 Kalman Gain22

Kalman Form

  • update 를 residual y = z - x 와 Kalman gain K = P / (P + R) 로 다시 작성
  • prior 에 K y 를 더해 posterior 계산, Bayesian 곱과 수학적으로 동일한 결과
  • 조건: P 상태 분산, Q 공정 잡음, R 측정 잡음, prior N(25, 0.53), 측정 N(26, 1)
def update(prior, measurement):
    x, P = prior        # mean and variance of prior
    z, R = measurement  # mean and variance of measurement
    y = z - x        # residual
    K = P / (P + R)  # Kalman gain
    x = x + K*y      # posterior
    P = (1 - K) * P  # posterior variance
    return gaussian(x, P)
def predict(posterior, movement):
    x, P = posterior # mean and variance of posterior
    dx, Q = movement # mean and variance of movement
    x = x + dx
    P = P + Q
    return gaussian(x, P)
prior = predict(gaussian(10., .2**2), gaussian(15., .7**2))
update(prior, gaussian(26., 1.))

Full Description of the Algorithm

Initialization

  • 필터 상태 초기화

4.18 Fixed Gain Filters39

Fixed Gain Filters

  • 저가 임베디드 프로세서는 부동소수점 회로가 없어 이 간단한 식도 부담
  • 분산이 상수면 분산과 gain 이 상수로 수렴, 그 gain 을 미리 구해 코드에 고정
  • 조건: K = 0.13232, 측정 분산 4.5, process 분산 2, 측정 40 개
vel, dt = 1., 1.
def update(x, z):
    K = .13232  # experimentally derived Kalman gain
    y = z - x   # residual
    x = x + K*y # posterior
    return x
def predict(x):
    return x + vel*dt

zs = [dog.move_and_sense() for _ in range(40)]
