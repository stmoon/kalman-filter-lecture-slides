10.2 A Quick Example08

A Quick Example

  • 상태 [x, ] 의 1 차원 등속 추적, 행렬 F, H 대신 함수 fx(), hx() 를 필터에 전달, 나머지 설계는 동일
  • fx() 를 행렬 곱이 아닌 식으로 작성, 같은 자리에 임의의 비선형 함수도 넣을 수 있음
  • 조건: Julier sigma points, 측정 z = i + N(0, 0.5^2), 50 단계, P = 10 I, R = 0.5, Q 분산 0.03
def fx(x, dt):
    xout = np.empty_like(x)
    xout[0] = x[1] * dt + x[0]
    xout[1] = x[1]
    return xout
def hx(x):
    return x[:1] # return position [x]
ukf = UnscentedKalmanFilter(dim_x=2, dim_z=1, dt=1., hx=hx, fx=fx, points=sigmas)
ukf.P *= 10
ukf.R *= .5
ukf.Q = Q_discrete_white_noise(2, dt=1., var=0.03)
zs, xs = [], []
for i in range(50):
    z = i + randn()*.5
    ukf.predict()
    ukf.update(z)
    xs.append(ukf.x[0])
    zs.append(z)
plt.plot(xs); plt.plot(zs, marker='x', ls='');

Choosing Sigma Points

  • 목표: 함수에 대한 사전 지식 없이 모든 함수에 쓰는 일반 알고리즘, 가장 적은 점의 수
  • 기준: 항등 함수 f(x) = x 에서 입력과 출력이 같아야 함, 아니면 필터 발산
  • 1 개: 평균 그대로면 선형 Kalman filter, 평균 + 델타면 항등 함수에서 발산
  • 2 개: 평균과 다른 한 점, 비대칭이 생겨 항등 함수를 만족시키기 어려움
  • 3 개: 평균과 양쪽에 하나씩, Gaussian 의 대칭성 유지
핵심: 차원당 3 개의 점, 평균과 그 양쪽 대칭 위치에서 시작

def merwe_weights(n, alpha, beta, kappa):
    lambda_ = alpha**2 * (n + kappa) - n
    Wc = np.full(2*n + 1,  1. / (2*(n + lambda_)))
    Wm = np.full(2*n + 1,  1. / (2*(n + lambda_)))
    Wc[0] = lambda_ / (n + lambda_) + (1. - alpha**2 + beta)
    Wm[0] = lambda_ / (n + lambda_)
    return Wm, Wc

def sigma_points(X, P, alpha, kappa):
    n = len(X)
    lambda_ = alpha**2 * (n + kappa) - n
    sigmas = np.zeros((2*n+1, n))
    U = scipy.linalg.cholesky((n+lambda_)*P) # sqrt
    sigmas[0] = X
    for k in range(n):
        sigmas[k+1]   = X + U[k]
        sigmas[n+k+1] = X - U[k]
    return sigmas

def my_unscented_transform(sigmas, Wm, Wc, Q):
    x = np.dot(Wm, sigmas)
    kmax, n = sigmas.shape
    P = np.zeros((n, n))

    return x, P

from numpy.linalg import inv
def update(self, z):
    sigmas_f, sigmas_h = self.sigmas_f, self.sigmas_h
    # transform sigma points into measurement space
    for i in range(self._num_sigmas):
        sigmas_h[i] = self.hx(sigmas_f[i])
    # mean and covariance of prediction passed through UT
    zp, Pz = my_unscented_transform(sigmas_h, self.Wm, self.Wc, self.R)
    # compute cross variance of the state and the measurements
    Pxz = np.zeros((self._dim_x, self._dim_z))
    for i in range(self._num_sigmas):
        Pxz += self.Wc[i] * np.outer(sigmas_f[i] - self.xp, sigmas_h[i] - zp)
    K = np.dot(Pxz, inv(Pz)) # Kalman gain
    self.x = self.xp + np.dot(K, z - zp)
    self.P = self.Pp - np.dot(K, Pz).dot(K.T)

    """ takes a state variable and returns the measurement

def state_mean(sigmas, Wm):
    x = np.zeros(3)
    sum_sin = np.sum(np.dot(np.sin(sigmas[:, 2]), Wm))
    sum_cos = np.sum(np.dot(np.cos(sigmas[:, 2]), Wm))
    x[0] = np.sum(np.dot(sigmas[:, 0], Wm))
    x[1] = np.sum(np.dot(sigmas[:, 1], Wm))
    x[2] = atan2(sum_sin, sum_cos)
    return x
def z_mean(sigmas, Wm):
    z_count = sigmas.shape[1]
    x = np.zeros(z_count)
    for z in range(0, z_count, 2):
        sum_sin = np.sum(np.dot(np.sin(sigmas[:, z+1]), Wm))
        sum_cos = np.sum(np.dot(np.cos(sigmas[:, z+1]), Wm))
        x[z] = np.sum(np.dot(sigmas[:,z], Wm))
        x[z+1] = atan2(sum_sin, sum_cos)
    return x

def run_localization(cmds, landmarks, sigma_range, sigma_bearing, ellipse_step=1, step=10):
    ukf = make_ukf(landmarks, sigma_range, sigma_bearing)
    sim_pos, track = ukf.x.copy(), []
    for i, u in enumerate(cmds):

10.16 Discussion69

Discussion

UKF

  • 2n + 1 개 sigma point 와 f(x), h(x) 함수 작성
  • 각도의 모듈러 연산 처리가 번거로운 부분
  • 개념이 단순, 여러 점을 표본해 강한 비선형에서 정확

EKF

  • 한 점에서 선형화해 선형 Kalman filter 에 통과
  • 꽤 어려운 수학, 닫힌 해가 없으면 반복 해법
  • UKF 가 최소한 비슷하고 보통 더 좋은 성능
  • 권장: UKF 부터 구현, 발산 시 큰 피해가 나는 시스템은 정교한 분석과 실험으로 필터 선택
  • 사용한 UKF: scaled unscented filter 를 Van der Merwe 방식으로 파라미터화한 형태
  • sigma point filter 계열: 점을 고르고 가중하는 방식이 다른 여러 필터, SVD 를 쓰는 필터 등 다양
결론: UKF 는 sigma point filter 의 한 형태, 비선형 위치인식 문제의 실용적인 출발점
