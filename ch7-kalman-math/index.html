7.2.4 The Matrix Exponential11

Constant Velocity with expm()

  • 등속 모델 A 의 matrix exponential 을 scipy 의 expm() 으로 계산, 출력된 F 가 [[1, Δt], [0, 1]] 과 일치
  • 구한 F 를 x_k = F x_k-1 로 20 번 적용, 위치가 일정한 기울기로 증가하는 등속 운동 확인
  • 조건: A = [[0, 1], [0, 0]], dt = 0.1 s, 초기 위치 0 m, 속도 2 m/s
import numpy as np
from scipy.linalg import expm
dt = 0.1
A = np.array([[0, 1],
              [0, 0]])
F = expm(A*dt)
print(F)
# propagate x = [position, velocity]
x = np.array([0., 2.])
xs = [x]
for k in range(20):
    x = F @ x
    xs.append(x)
plt.plot(np.arange(21)*dt, np.array(xs)[:, 0], 'o-')
plots.set_labels(x='time (s)', y='position (m)')
[[1. 0.1] [0. 1. ]]

7.2.5 Time Invariance15

Example: Mass-Spring-Damper Model

  • 질량-스프링-감쇠 시스템의 F 를 급수 앞 두 항 I + AΔt 와 expm() 으로 각각 구해 같은 초기 상태를 전파
  • 두 항 근사(점선)는 진폭이 커지고 정확한 해는 감쇠, 출력된 (AΔt)^2/2! 로 앞 두 항이 충분한지 직접 확인
  • 조건: m = 1 kg, k = 4 N/m, c = 0.2 N s/m, dt = 0.1 s, 초기 x = 1 m, 100 단계
from scipy.linalg import expm
m, k, c = 1., 4., 0.2   # mass, spring constant, damping
dt = 0.1
A = np.array([[0., 1.], [-k/m, -c/m]])
F2 = np.eye(2) + A*dt   # first two terms
F = expm(A*dt)          # matrix exponential
print((A*dt) @ (A*dt) / 2)  # (A dt)^2 / 2!
x = x2 = np.array([1., 0.])
xs, x2s = [x], [x2]
for _ in range(100):
    x, x2 = F @ x, F2 @ x2
    xs.append(x); x2s.append(x2)
ts = np.arange(101)*dt
plt.plot(ts, np.array(xs)[:, 0], label='expm')
plt.plot(ts, np.array(x2s)[:, 0], '--', label='I + A dt')
plots.set_labels(x='time (s)', y='x (m)')
plt.legend(loc=3);
[[-0.02 -0.001] [ 0.004 -0.02 ]]

7.3.1 Continuous White Noise Model20

Q for Position, Velocity, Acceleration

  • 위치, 속도, 가속도 모델의 Q 를 SymPy 로 기호 적분, 가독성을 위해 Φs 를 행렬 밖으로 분리
  • 결과의 위치 항은 Δt^5 에 비례, 가속도 항은 Δt 에 비례해 차수가 높은 상태일수록 빠르게 작아짐
  • 조건: F 는 3 x 3 등가속 모델, Q_c 는 가속도 항만 Φs
import sympy
from sympy import Matrix, integrate, symbols

dt, phi = symbols(r'\Delta{t} \Phi_s')
F_k = Matrix([[1, dt, dt**2/2],
              [0,  1,      dt],
              [0,  0,       1]])
Q_c = Matrix([[0, 0, 0],
              [0, 0, 0],
              [0, 0, 1]])*phi

Q = integrate(F_k * Q_c * F_k.T, (dt, 0, dt))

# factor phi out of the matrix to make it more readable
Q = Q / phi
plots.show_matrix(Q, phi)

7.3.1 Continuous White Noise Model21

0th and 1st Order Models

  • 같은 적분을 0 차(위치만) 모델과 1 차(위치, 속도) 모델에 적용해 이산 process noise 계산

from sympy import Matrix, integrate, symbols
dt, phi = symbols(r'\Delta{t} \Phi_s')

F_k = Matrix([[1]])
Q_c = Matrix([[phi]])
Q0 = integrate(F_k*Q_c*F_k.T, (dt, 0, dt))

F_k = Matrix([[1, dt],
              [0, 1]])
Q_c = Matrix([[0, 0],
              [0, 1]]) * phi
Q1 = integrate(F_k * Q_c * F_k.T, (dt, 0, dt)) / phi

plt.subplot(1, 3, 1)
plots.show_matrix(Q0, title='0th order')
plt.subplot(1, 3, (2, 3))
plots.show_matrix(Q1, phi, title='1st order')

7.3.2 Piecewise White Noise Model23

Q for 1st and 2nd Order Models

  • 구간 상수 잡음 모델의 Q = Γ σv² Γ^T 를 1 차와 2 차 모델에 대해 SymPy 로 계산
  • 2 차 모델은 잡음을 discrete time Wiener process 로 가정해 Γ = [Δt²/2, Δt, 1]^T
  • 이 모델이 참이라는 근거는 없으며 편리하고 결과가 좋음, 잡음을 jerk 에 적용하는 모델도 가능
  • 조건: σv² 는 행렬 밖으로 분리, 왼쪽 1 차 (2 x 2), 오른쪽 2 차 (3 x 3)
from sympy import Matrix, symbols
dt, var = symbols(r'\Delta{t} sigma^2_v')

v = Matrix([[dt**2 / 2], [dt]])
Q1 = v * var * v.T
Q1 = Q1 / var  # factor variance out of the matrix

v = Matrix([[dt**2 / 2], [dt], [1]])
Q2 = v * var * v.T
Q2 = Q2 / var

plt.subplot(1, 2, 1)
plots.show_matrix(Q1, var, title='1st order')
plt.subplot(1, 2, 2)
plots.show_matrix(Q2, var, title='2nd order')

P = np.array([[4., 1.],
              [1., 2.]])     # prior covariance
H, R = np.array([[1., 0.]]), np.array([[1.]])

def euler(t, tmax, y, dx, step=1.):
    ys = []
    while t < tmax:
        y = y + step*dx(t, y)
        ys.append(y)
        t +=step
    return ys

def runge_kutta4(y, x, dx, f):
    """computes 4th order Runge-Kutta for dy/dx"""
    k1 = dx * f(y, x)
    k2 = dx * f(y + 0.5*k1, x + 0.5*dx)
    k3 = dx * f(y + 0.5*k2, x + 0.5*dx)
    k4 = dx * f(y + k3, x + dx)
    return y + (k1 + 2*k2 + 2*k3 + k4) / 6.
t, y, dt = 0., 1., .1
ys, ts = [], []
def func(y,t): return t*np.sqrt(y)
while t <= 10:
    y = runge_kutta4(y, t, dt, func)
    t += dt
    ys.append(y); ts.append(t)
exact = [(t**2 + 4)**2 / 16. for t in ts]
plt.plot(ts, ys, label='RK4')
plt.plot(ts, exact, '--', label='exact')
plt.legend()
error = np.array(exact) - np.array(ys)
print("max error {:.5f}".format(max(error)))

7.8 Converting Kalman Filter to a g-h Filter43

Gain g Varies with Time

  • 1 차원 Kalman filter 를 반복하며 매 단계 Kalman gain K 와 g_n = (추정 분산) / (측정 분산) 을 함께 기록
  • 두 값이 모든 단계에서 겹침, g 는 상수가 아니라 분산이 변하는 동안 단계마다 바뀌다가 수렴
  • g, h 는 측정과 예측의 분산, 공분산으로 결정, 두 입력의 품질로 정한 비율만큼 둘 사이의 점을 선택
  • 조건: 초기 분산 500, process 분산 Q = 1, 측정 분산 R = 10, 30 단계
P = 500.            # initial variance
Q, R = 1., 10.      # process and measurement variance
gs, Ks = [], []
for k in range(30):
    P = P + Q           # predict
    K = P / (P + R)     # Kalman gain
    P = (1 - K) * P     # posterior variance
    Ks.append(K)
    gs.append(P / R)    # g_n = sigma_x^2 / sigma_y^2

plt.plot(Ks, 'o', ms=10, label='Kalman gain K')
plt.plot(gs, lw=3, label='g_n = P / R')
plots.set_labels(x='step', y='gain')
plt.legend();
