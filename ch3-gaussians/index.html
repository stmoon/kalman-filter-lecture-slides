N = 10000
samples = []
for r in np.random.rand(N):
    if r <= .80: samples.append(1)
    elif r < .95: samples.append(3)
    else: samples.append(5)

running = np.cumsum(samples) / np.arange(1, N + 1)
print('expected value ~', running[-1])
plt.plot(running)

3.11 Computational Properties of Gaussians20

Product of Gaussians

  • 두 Gaussian g1, g2 를 같은 x 위에서 원소별로 곱하고 합으로 나눠 정규화
  • 곱한 결과(점선)도 Gaussian 모양, 평균은 두 평균 사이에 위치
  • 합은 Gaussian, 곱은 Gaussian 에 비례, Kalman filter 가 계산 가능한 핵심 성질
  • 조건: g1 = N(0.8, 0.1), g2 = N(1.3, 0.2), x = -1 ~ 3
x = np.arange(-1, 3, 0.01)
g1 = gaussian(x, mean=0.8, var=.1)
g2 = gaussian(x, mean=1.3, var=.2)
plt.plot(x, g1, x, g2)

g = g1 * g2 # element-wise multiplication
g = g / sum(g) # normalize
plt.plot(x, g, ls='-.');

Nonlinear Functions

3.12 Putting it all Together22

Discrete Update Revisited

  • 이산 필터의 update: 각 칸의 prior 와 likelihood 를 원소별로 곱한 뒤 정규화
  • 결과 posterior 는 한 위치 근처에 몰린 분포, 10 칸이므로 곱셈 10 번
  • 다차원의 큰 배열이면 수십억 번의 곱셈과 많은 메모리가 필요
  • 조건: 10 칸 prior, likelihood (정수 빈도를 전체 합으로 정규화)
def normalize(p):
    return p / sum(p)

def update(likelihood, prior):
    return normalize(likelihood * prior)

import random, math
def rand_student_t(df, mu=0, std=1):
    x = random.gauss(0, std)
    y = 2.0*random.gammavariate(0.5*df, 2.0)
    return x / (math.sqrt(y / df)) + mu
def sense_t():
    return 10 + rand_student_t(7)*2
zs = [sense_t() for i in range(5000)]

3.17 Summary and Key Points35

Summary

  • Gaussian: 연속 확률 분포, 평균 mu 와 분산 sigma^2 두 매개변수로 완전히 표현
  • mu: 모든 가능한 값의 평균
  • sigma^2: 측정이 평균에서 얼마나 퍼지는지
  • sigma: 분산의 제곱근, 데이터와 같은 단위
  • 한계: 자연의 많은 현상이 정규분포에 가깝지만 수학이 완벽하지는 않음
  • Bayes: p(x | z) 는 어렵고 p(z | x) 는 쉬움, Bayes 로 앞의 것을 계산
결론: Gaussian 과 Bayes 정리의 결합이 필터 구성의 기반
